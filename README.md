# Boyut Kargo

Sonsuz evren. Asgari ücret. Dört absürt evrende 16 teslimat içeren Türkçe, çevrimdışı bulmaca oyunu.

Bu depo oyunun statik indirme sayfasını içerir. Oyun paketleri ve doğrulama durumu [sürüm notlarında](https://github.com/harunaras/boyut-kargo/releases) bulunur. Kaynak kod ve imzalama anahtarları bu depoya dahil değildir.

Sayfa harici font veya izleme servisi kullanmaz. Oyun görüntüleri gerçek Windows oynatıcısında 1920×1080 çözünürlükte alınmıştır. Atkinson Hyperlegible fontunun lisansı `licenses.txt` içindedir.

Yerel önizleme: bu klasörde `python -m http.server 8765 --bind 127.0.0.1` çalıştırın; `http://127.0.0.1:8765` adresini açın.
